# Agents

Store reusable agent definitions as `<agent-name>.md`.

Each definition should describe its purpose, responsibilities, constraints, and expected output. Document tool-specific configuration when an agent requires it.

Give new agents a unique, simple personal name alongside their descriptive role. Include that short name in the canonical identifier, title, discovery description where supported, and instructions for delegating work. A nickname should resolve to one canonical definition rather than a duplicate agent file.
